# E05 App del técnico

PWA para el celular Android: órdenes asignadas, cierre con opciones predefinidas, repuestos sin precios, foto y firma. Funciona con conexión y guarda el borrador del cierre si se corta la señal (ADR 0009).

Las historias de esta épica están en esta carpeta, un archivo por historia. El índice general está en [../INDEX.md](../INDEX.md).
